# sec-test

安全测试项目

## 简介

本项目用于安全相关的测试和验证工作，包含常见安全漏洞的演示和测试用例。

## 功能特性

- SQL注入测试
- XSS跨站脚本测试
- CSRF跨站请求伪造测试
- 文件上传漏洞测试

## 环境要求

- JDK 8+
- Maven 3.6+
- Git

## 使用说明

1. 克隆仓库
   ```bash
   git clone https://github.com/sunjunxiang-it/sec-test.git
   ```
2. 进入项目目录
   ```bash
   cd sec-test
   ```
3. 根据需要运行相关测试
